### Before you submit to Play Console

1. Host the HTML at a **public HTTPS URL** (required by Google Play). Options:
   - Cloudflare Pages / Netlify drop-folder deploy
   - A separate **public** GitHub Pages repo (this app repo is private)
   - Any static host you control
2. Paste that URL into Play Console → **App content** → **Privacy policy**.
3. Align the **Data safety** form with this policy:
   - Documents stay on-device (no cloud upload of library files)
   - Crashlytics only when the user opts in (default off)
   - No Firebase Analytics / advertising ID collection
   - No in-app purchases or subscriptions in the current build
