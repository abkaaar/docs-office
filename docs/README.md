# Docs (Play Store assets)

## Privacy policy

File: [`privacy-policy.html`](privacy-policy.html)

### Before you submit to Play Console

1. Replace every `YOUR_EMAIL@example.com` with your real support email.
2. Host the HTML at a **public HTTPS URL** (required by Google Play). Options:
   - GitHub Pages (repo must be public, or use a public `docs` site / separate public repo)
   - Netlify / Cloudflare Pages drop-folder deploy
   - Any static host you control
3. Paste that URL into Play Console → **App content** → **Privacy policy**.
4. Align the **Data safety** form with this policy: documents stay on-device; Crashlytics only when the user opts in (default off).
